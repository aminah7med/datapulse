# DataPulse

منصة منظّمة وقابلة للتوسّع لبناء تدفقات البيانات ومراقبة جودتها وإدارة الحوادث المرتبطة بها. هذا المستودع يضع الأساس المعماري فقط؛ لا يتضمن بعد منطقًا تنفيذيًا للمنتج.

## البنية

```text
.
├── .github/workflows/       # فحوصات CI
├── airflow/dags/            # تعريف تدفقات Airflow
├── database/                # تغييرات المخطط والبيانات المرجعية
│   ├── migrations/
│   └── seeds/
├── docs/                    # التصميم والمخطط وقرارات ADR
├── requirements/            # ملفات متطلبات البيئة
├── scripts/                 # أدوات التطوير والتشغيل المساندة
├── src/datapulse/           # الحزمة الأساسية بنمط src
│   ├── config/
│   ├── incidents/
│   ├── ingestion/
│   ├── quality/
│   ├── storage/
│   ├── transformation/
│   └── validation/
└── tests/
    ├── integration/
    └── unit/
```

## حدود المكونات

- **ingestion** يستقبل البيانات من المصادر ويعزل تفاصيل الموصلات.
- **validation** يتحقق من شكل البيانات وصحتها قبل تمريرها.
- **transformation** يطبق التحويلات على بيانات مقبولة.
- **quality** يقيس مؤشرات الجودة ويصدر نتائج قابلة للتتبع.
- **incidents** يمثل الانحرافات والتنبيهات ودورة معالجتها.
- **storage** يعزل التعامل مع قواعد البيانات ومخازن البيانات.
- **config** يوفر إعدادات التطبيق المشتركة دون ربطها بمكوّن بعينه.
- **Airflow** ينسّق تدفقات العمل ويستدعي واجهات الحزمة بدل احتواء منطق المجال.

## البدء

يتطلب التطوير Python 3.12 أو أحدث وDocker Compose عند الحاجة إلى قاعدة البيانات المحلية.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pytest
ruff check .
```

انسخ `.env.example` إلى `.env` وعدّل القيم محليًا قبل تشغيل الخدمات. لا تضع الأسرار في Git.

لتشغيل قاعدة البيانات المحلية:

```powershell
docker compose up -d database
```

## التطوير والتحقق

- تعريف الحزمة والاعتماديات وإعدادات الأدوات في `pyproject.toml`.
- اختبارات الوحدة والتكامل منفصلة تحت `tests/`.
- سير عمل GitHub Actions يشغّل فحوصات التنسيق والاختبارات عند الدفع وفتح طلبات الدمج.
- يشرح [docs/design/README.md](docs/design/README.md) التصميم وحدود المكونات.
- يشرح [docs/database/README.md](docs/database/README.md) تنظيم تغييرات قاعدة البيانات.
- تحفظ القرارات المعمارية المؤثرة كسجلات ADR تحت `docs/decisions/`.

## الحالة الحالية

الهيكل والوثائق والإعدادات التمهيدية فقط؛ وحدات المجال وDAGs والترحيلات وأدوات التشغيل فارغة عمدًا إلى حين تحديد متطلبات التنفيذ.
