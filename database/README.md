# Database

يحفظ هذا المجلد تغييرات مخطط قاعدة البيانات والبيانات المرجعية بعيدًا عن منطق التطبيق.

- `migrations/`: تغييرات صغيرة ومرتبة زمنيًا للمخطط، مع توثيق التوافق وخطة التراجع عند الحاجة.
- `seeds/`: بيانات مرجعية قابلة لإعادة التحميل؛ لا تضع بيانات إنتاج أو أسرارًا هنا.

لم يُعتمد إطار migrations بعد. سجّل القرار وأداة التنفيذ في `docs/decisions/` قبل إضافة ترحيلات فعلية.
