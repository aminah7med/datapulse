# ADR 0001: تنظيم الحزمة بنمط src وحدود المجال

- الحالة: مقبول
- التاريخ: 2026-10-11

## السياق

يحتاج DataPulse إلى أساس يفصل منطق المنتج عن تنسيق التدفقات والاختبارات والإعدادات، ويسمح بإضافة مكونات مستقبلًا دون تحميل مجلد واحد مسؤوليات متباينة.

## القرار

اعتماد نمط `src/` للحزمة `datapulse` وتقسيمها إلى حزم مجال مستقلة للاستيعاب والتحقق والتحويل والجودة والحوادث والتخزين والإعدادات. تبقى DAGs في `airflow/dags/`، والاختبارات في مساري الوحدة والتكامل.

## البدائل

- وضع الحزمة في جذر المستودع، ما يجعل استيراد ملفات العمل أسهل عرضة لإخفاء أخطاء التغليف.
- تقسيم المستودع إلى عدة حزم مستقلة، وهو تعقيد غير مبرر قبل وجود حدود نشر أو ملكية مستقلة.

## النتائج

- يتطلب تثبيت التطوير تثبيت المشروع بصيغة editable.
- يمكن اختبار حدود الحزم وتوسيعها تدريجيًا.
- لا يفرض القرار أداة قاعدة بيانات أو تنفيذًا محددًا للتدفقات.
