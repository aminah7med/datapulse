# تصميم قاعدة البيانات

لا يوجد مخطط فعلي أو محرك قاعدة بيانات معتمد في هذه المرحلة. ملفات `database/migrations/` و`database/seeds/` أماكن مخصصة للترحيلات والبيانات المرجعية المستقبلية.

قبل اعتماد المخطط، وثّق الكيانات والعلاقات والملكية والاحتفاظ والفهارس وسياسة التوافق. يجب أن تكون الترحيلات مرتبة، مراجعة، وقابلة للتطبيق على قاعدة جديدة وقاعدة قائمة.
